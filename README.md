# 🎬 Streaming Interface

Projeto Front-End desenvolvido para fins educacionais, inspirado em interfaces modernas de plataformas de streaming.

## 🚀 Sobre o projeto

A aplicação apresenta uma interface de streaming com catálogo de filmes e séries, vídeo de destaque, controles de reprodução e informações dinâmicas sobre os títulos selecionados.

O projeto foi desenvolvido com foco na prática de desenvolvimento Front-End, manipulação do DOM e criação de uma interface responsiva.

> **Projeto educacional independente. Não possui vínculo oficial com a Netflix ou qualquer outra plataforma de streaming.**

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Google Fonts

## ✨ Funcionalidades

- 🎥 Vídeo de destaque em tela cheia
- 🔊 Controle de áudio
- ▶️ Reprodução e pausa do vídeo
- 🎞️ Catálogo dinâmico de filmes e séries
- ◀️▶️ Navegação por carrossel
- 🔎 Seleção de títulos
- 📋 Modal com informações do filme ou série
- 📱 Layout responsivo para diferentes tamanhos de tela
- 🎬 Troca dinâmica do vídeo conforme o título selecionado
