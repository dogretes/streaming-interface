# Netflix Clone

Projeto de front-end desenvolvido como prática de HTML, CSS e JavaScript, inspirado na interface de uma plataforma de streaming.

O projeto apresenta um catálogo de filmes e séries com navegação interativa, reprodução de vídeos e atualização dinâmica das informações de cada título.

## 🎬 Funcionalidades

- Catálogo de filmes e séries;
- Carrossel para navegação entre os títulos;
- Seleção de filmes pelo catálogo;
- Alteração dinâmica do título e da descrição;
- Reprodução de vídeo correspondente ao filme selecionado;
- Botão para reproduzir e pausar o vídeo;
- Controle de áudio;
- Modal com informações do filme;
- Exibição de gênero e ano de lançamento;
- Animações e transições;
- Layout responsivo para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Google Fonts
